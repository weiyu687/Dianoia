# 在线题库：教师端使用与部署

本轮实现自主练习内容的创建、核对与发布。教师工作台的「在线题库」是独立入口；管理端保持独立。学生账户、实际作答和继续练习记录在学生端阶段实现，当前「预览」仅向所属教师开放，不向匿名或学生暴露答案。

## 教师操作

1. 在当前课程创建题库，填写名称和简介，选择默认封面或上传图片后拖动、缩放裁剪。提供六种原创主题，支持深浅色界面。
2. 在「设置」中维护章节和子章节、共享阅读材料及参考资料范围。题目可归入任意子章节，共享材料可用于一组子题。
3. 手工录入单选、多选、判断、填空或解答题；编程等专业内容使用标签区分。题干、选项、参考答案和解析支持富文本、图片、表格、可再编辑公式。填空参考表达可通过公式面板输入。公式按钮或 `Ctrl/⌘+M` 打开面板，双击公式重新编辑；表格末格按 `Ctrl/⌘+Enter` 或点击表格下方段落按钮继续输入。
4. 「AI 生成」按题型、数量、难度、语言、知识点、资料页码及要求起草，每批最多 20 题；后台每三题保存一批。生成内容为待核对草稿。单题的「AI 修改本题」先显示候选，采纳后仍需核对。「补充答案与解析」保留原题干和选项；「优化干扰项」保留题干与正确选项。
5. DOC/DOCX 或当前课程已确认试卷可导入候选，选择后入库。导入按题号、段落和已有题目标记识别；浮动图片、复杂 Word 排版及部分公式需要教师手动补全，界面会列出识别警告。这里不承诺 Word 整页保真导入。
6. 题目支持检索、类型筛选、待确认筛选、批量移动、标签、参与发布与删除。选择题答案按稳定选项 ID 保存，编辑选项文字不会错位。修改题目正文后需重新确认。
7. 预览核对题干、答案和解析，执行发布预检，再选择当前课程全部班级或指定班级发布。只有已确认且参与发布的有效题目进入发布版本。继续修改保存为草稿，点击「发布更新」才创建下一版本。下架关闭发布；归档将同一题库移入已归档，恢复不会复制。复制是明确的独立操作。

## 安装与运行

安装 `backend/requirements.txt` 和前端锁文件依赖。使用当前兼容 Chat Completions 的模型配置，复用课程资料库，不新增 TTS/GPU 依赖。DOC 导入仍需要 LibreOffice Writer。

从 `backend` 目录执行：

```powershell
..\.venv\Scripts\python.exe -m app.migrate
..\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

另一个终端启动题库 worker：

```powershell
Set-Location backend
..\.venv\Scripts\python.exe -m app.question_banks.worker
```

API 和 worker 必须读取相同的数据库、`DIANOIA_DATA_DIR`、模型配置。worker 与数字课程的 `course_worker` 是不同进程，可分别部署。任务使用数据库租约和心跳，中断超过两分钟后可恢复；失败时页面可「继续生成」，已保存批次保留。未运行 worker 时任务保持排队。生产环境应由进程管理器负责重启。

SQLite 本地启动自动执行版本迁移；PostgreSQL 必须在 API/worker 启动前显式运行 `python -m app.migrate`。迁移目录 `backend/migrations` 包含旧表基线和八张题库表，已有表保留。已有部署升级前备份数据库并在副本验收；不提供自动清表式降级。数据库和私有 `question-banks` 附件目录需要共同备份，发布版本引用的图片须长期保留。

## 数据和权限

- 题库、题目、图片、生成任务及发布预览均校验课程授权和归属教师，同一课程的其他教师不能读取个人题库。
- 题目保存不可变版本，答案单独按版本存储。发布事务冻结题目、答案、章节、材料、封面、来源名称及班级范围。重复发布、导入和新题保存使用请求键去重；修订号冲突返回 409，避免覆盖其他窗口修改。
- 题目正文是受控 JSON，不持久化任意 HTML；图片真实解码、限制大小并重新编码。封面上限 5 MB、20 MP；单个题库最多 2000 题，单题内容上限 240 KB，发布快照上限 8 MB。
- 课程资料按教师选择的章节或页码读取并检查权限，模型引用必须落在允许范围。大模型生成仍需教师检查题意、答案和学科准确性。

## Agent

安装原有 `requirements-agent.txt`，使用支持工具调用的模型。Agent 提供列举题库、读取章节/题目/答案、新建草稿、后台生成、保存单题草稿及查询进度六个工具，返回编辑链接。使用 `backend/app/skills/question-banks/SKILL.md` 的结构说明。Agent 不能发布，也不能将生成内容直接标记已确认。

## 验证范围

后端集成回归覆盖版本与答案校验、发布幂等、权限隔离、Word 候选导入、图片封面、公式、任务部分失败续做和 Agent 草稿规则。Windows Chrome 验证了深浅主题、子章节、材料、裁剪、图片、表格、公式保存重开、发布更新和教师预览；真实模型按讲义指定页生成矩阵练习。PostgreSQL 生产实例、真实学校题库规模和多学科生成质量需在部署与业务验收时进一步验证。
