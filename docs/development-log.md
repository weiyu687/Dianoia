# 开发日志

## 2026-11-12｜完善中文教案编辑、AI 写作和 PDF 预览

- 添加常用中文字体与原生插表入口。整篇生成和光标写作都可将模型生成的 Markdown 管道表格转成 Word 表格。
- 写作选项从光标快捷键或文字选区打开。候选在画布中灰显，按 Tab 采纳，按 Esc 取消。
- 资料、教案和模板改用 PDF.js 原生连续查看器，滚动更新页码，可输入页码或通过资料目录跳转。
- 用模型替身验证光标前后文、选区改写取消、候选表格采纳与 DOCX 保存。使用 315 页 PDF 验证跳页和按需渲染，用学校 Word 模板验证四页预览。后端回归及前端生产构建通过。

## 2026-11-12｜Word 分页教案与技术栈记录

- 教案改为 Word 分页编辑。支持新建空白文档、从资料生成草稿，以及上传、预览、重命名、删除和选用 DOC 或 DOCX 模板。
- DOCX 正文和模板独立存储。保存时检查版本并更新供 Agent 读取的文本。旧教案可直接打开，在首次保存时写入 DOCX 正文。
- 保留 PDF 预览与 DOCX、DOC、PDF 导出。写作建议显示在工具栏下方，快捷键打开续写，采纳时写入光标位置或替换选区。
- 使用中国矿业大学（北京）的旧版 Word 模板验证上传、四页显示、跳页、表格修改与 PDF 转换。用模型替身验证续写与重写，回归覆盖旧教案、权限隔离、版本冲突和模板副本。前端生产构建通过，Word 编辑器按路由加载，构建仍提示编辑器依赖体积较大。
- 补齐技术栈与选型记录，明确后续组件先确认选型，再同步记录依赖、运行条件与验证结果。

## 2026-11-12｜教师工作台和学校管理端首个可运行版本

- 建立独立 Vue 教师端、学校管理端和 FastAPI。实现角色登录、持久会话、课程授权、虚拟数据初始化、XLSX 预检与导入及教师账号开通和停用。

- 接通 PDF.js 预览、资料与教案多级目录、按资料页码创建教案、Tiptap 在线编辑及直接模型续写、重写。续写通过 Alt+反斜杠请求，Tab 采纳，Esc 取消。

- 验证前端生产构建、登录与角色隔离、重复导入、资料入库、教案编辑及版本冲突、DOCX/PDF 导出。Chrome 验证亮暗切换、续写快捷键与采纳、PDF 渲染和两端分入口。使用本地模型替身验证写作接口和 Deep Agents 工具调用。当前配置的真实模型服务返回 HTTP 402。
