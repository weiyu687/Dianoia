# 智能教育平台功能设计

状态为 v0.4，更新于 2026-11-19。

## 1. 建设范围

平台采用前后端分离架构，面向教师和学生，教师端与学生端使用独立入口。管理端不再纳入后续产品开发范围。当前已有的管理端代码仅作为历史兼容入口和虚拟数据导入方式保留，不集成进教师端，也不继续扩展。现有课程与教师任课关系用于教师授权；正式学生端上线前须完成学生账号身份来源方案。学情分析按单校试运行设计，教师权限限定在所负责的课程和教学班。

教师端从现有课程、班级和学生名册开展教学准备、内容创作、题库与学情分析。学情分析允许教师上传成绩、作业、考勤等格式不一的表格并确认字段映射。学生端独立开发，搜索所有教师明确发布到平台资源池的内容；学生不能访问教师上传的学情原表、班级统计或其他学生的个人计划。

教师工作台提供亮暗切换。资料库和教案各有管理列表，上传资料和新建教案从各自列表进入。教师 Agent 使用独立对话页面。

## 2. 角色与权限

| 角色 | 首期职责 | 数据访问范围 |
| --- | --- | --- |
| 教师 | 准备和发布教学资源，维护试卷与题库，导入表格、查看学情并制定计划 | 自己的备课材料和所负责课程/教学班中的学生记录；发布操作需教师明确确认 |
| 学生 | 学生端启用后搜索和使用平台已发布资源，查看发给本人的学习计划 | 所有登录学生可见的已发布资源；只可查看自己的计划和本人被授权的反馈 |

## 3. 管理端范围调整

取消管理端作为独立产品的继续开发，不在教师端嵌入管理功能。现有 `/admin/` 入口和虚拟样例数据导入暂留，仅供开发/迁移兼容；不新增管理工作流或以其作为学生账号的最终来源。学生身份来源须在学生端开发前单独确定（建议优先学校统一身份认证；无法接入时再设计教师发起的名册匹配和一次性领取流程）。

## 4. 教师端

### 4.1 课程工作区与教学资料

教师按学期、课程和教学单元管理资料与成果。教师上传课程大纲、教材节选、讲义、习题等资料，选择某次生成可使用的范围。生成结果保留关联的资料版本和生成任务记录。对于缺少资料支撑的生成内容，界面提示教师核实。

资料库支持上传、列表、搜索、重命名、下载原件、删除、预览与多级目录校对。目录节点有起止页。PDF 预览支持连续滚动、输入页码和点击目录跳转。上传后先校对，确认后进入可选资料范围。资料暂按文本层提取。

验收时，教师能在同一课程下找回资料、历史生成结果和已确认版本，并能从生成结果查看所选资料。

### 4.2 教案生成

教师设置主题、授课对象、课时和教学目标，选择参考资料。按资料章节或页码取材生成的草稿涵盖教学目标、重难点、教学活动、时间安排与课堂评价。教师可在分页编辑器中直接修改正文并保存。

教案管理支持列表、重命名、复制、归档、恢复与删除。教师可上传、预览、重命名和删除 DOC 或 DOCX 模板。新建教案可以使用空白页、使用模型生成草稿，或加载 Word 模板的完整内容与样式。使用模板时，教案独立保存。正文中可以使用多级标题、常用中文字体和 Word 表格。教案与模板的 PDF 预览支持连续滚动和页码跳转。教案支持导出 DOCX、PDF 和旧版 DOC。

空白教案及无模板 AI 生成使用简体中文 Word 样式，标题和小标题采用黑体，正文和表格采用宋体。归档把原教案移到已归档列表，恢复把同一份教案移回当前教案。复制操作创建新的教案副本。

光标处按 `Alt+\` 打开续写与按要求写选项。选中文字后自动显示润色、纠错、扩写、缩写与重写选项。模型建议在文档画布的光标或选区旁灰显，按 `Tab` 写入正文，按 `Esc` 取消。可识别的 Markdown 表格在生成教案和采纳建议时转成可编辑的 Word 表格。

使用模板生成时，服务端按 Word 中的 `{{栏目名}}` 或已识别的教学栏目写入副本。教务元数据从平台读取，填写内容在编辑器中可继续修改。没有识别到可填教学栏目时，草稿追加到模板末尾。整篇生成与编辑器写作均只读取教案所关联的已入库资料页，编辑器候选显示实际使用的资料名称与页码。

教师可通过工具栏在光标处插入本地 PNG、JPEG 或 GIF。图片嵌入教案文档，随文档保存和导出。

验收时，教师能从空白文档或学校 Word 模板创建教案，修改正文和表格、插入图片，保存后重新打开并核对 PDF 预览与导出。

### 4.3 知识框架生成与梳理

教师从教学资料提取课程、章节、知识点及其层级，补充知识点描述与资料来源。教师可合并重复项、调整层级、移动知识点、确认知识框架版本。已确认的知识点可用于标注题目和汇总学情。

验收时，教师能从大纲和讲义建立知识框架，调整一个知识点的归属并确认版本。引用已确认知识点的题目仍可追溯到对应记录。

### 4.4 知识架构图生成

基于选定的知识框架生成图形视图，支持查看层级、先修和关联关系。教师可编辑节点及关系，保存图稿并导出图片。对会引入循环先修依赖的编辑提供提示。

验收时，教师能从已确认的框架生成一张图，调整关系后保存并导出，图稿可追溯到生成时采用的框架版本。

#### 教师思维导图

教师可在当前课程搜索、重命名、复制和删除导图。可空白新建、从主题及所选资料生成，或从模板创建独立副本。编辑器提供多级主题、拖动换序和换父节点、撤销与重做、分支折叠、缩放、主题样式、备注和大纲定位，保存时校验版本。PNG 导出展开全部分支，隐藏备注徽标，默认关闭参考资料页码标注。

插入工具支持关联线、分支概要、外框、标注、图片、图标、网页链接、同图节点双向链接和资料库附件。公式、表格与代码块支持在节点弹窗编辑。编辑器按资料 ID 分配全图编号及颜色，资料面板可查看编号对应的文件，点击节点徽标可查看该文件的引用页。

导图及单个节点可引用资料库的章节或页码范围。教师可从节点引用打开原资料并定位页码。勾选导出标注后，资料名称集中显示在图底，节点仅显示页码。涉及多份资料时，节点页码和图底的资料名称使用一致的编号。整图选用的页码范围显示在对应资料名称后。AI 只接收所选范围内有正文的页面，引用由后端核对。教师 Agent 复用导图列表、读取及生成服务。

模板库按教学场景展示可预览的内置模板，并提供「我的模板」。教师可从零制作、编辑、重命名和删除个人模板，也可从现有导图存为模板。模板保留结构、文字和样式，课程资料引用留在原导图。模板创建的导图独立保存。

验收时使用有子章节的中文资料生成导图，核对节点页码，拖动节点并保存，重新打开后下载高清 PNG。另用内置模板和个人模板各创建一份导图，核对修改隔离。[知犀模板知识库](https://help.zhixi.com/guide/230.html) · [BEA 2025 教育概念图研究](https://aclanthology.org/2025.bea-1.58/) · [导图生成评估](https://arxiv.org/abs/2501.09457)

### 4.5 课件 PPT 生成

教师可从空白页和教学模板创建课件。在画布上调整页序、对象与图层，编辑文字、图片、图形、表格、图表和讲者备注。可将课件另存为个人模板，选择是否保留示例内容，并在模板库管理。

教师可引用当前课程的教案和资料页码，审核逐页大纲后生成可编辑课件。局部 AI 可提出更换当前页、改写所选文本框、生成讲者备注或插入新页的候选。教师确认后采纳并保存。跨页引用由已挂载的资料范围和任课权限校验。

通用主题提供封面、配色和正文风格。根据内容选择对照表、代码、流程、卡片等分页版式。教师可用 LaTeX 或数学键盘插入公式并编辑，在放映画面上点击进入下一页。

模板库支持完整逐页预览和直接用于手工或 AI 创建。整稿配置包含语言、写作风格、内容密度、讲者备注和图表策略。生成的图表能编辑数据，支持使用教师提供的数据或课件内已挂载资料中可核对的类别和数值。教师可显式允许示例数据。

教师可上传 MP3 和 H.264/AAC MP4，在本课程复用并放入指定页。对象可设置淡入、向上飞入、缩放强调或淡出，逐项调整次序、触发和时长。网页放映时先处理本页动画，再执行翻页。导出的 PPTX 嵌入媒体和动画时序，PDF 保留静态课件和媒体标记。

验收时，教师能保存并重开编辑结果，在浏览器放映或查看分页 PDF，并用 PowerPoint 或 WPS 打开 PPTX，核对页序、备注与可编辑对象。既有 PPTX 导入、母版和动画适配在后续阶段验证。

### 4.6 数字课程与数字人

面向高校慕课录制场景。教师在数字课程专用页面上传 PPT 或选择已生成的课件版本，按页生成口播稿，编辑分段脚本与字幕。教师选择预置数字人，或上传经授权的形象素材，并选择预置语音或上传本人或授权的参考语音。语音组件选型时验证单段参考音频的零样本合成和少量样本适配的适用条件。教师先预览片段，确认后提交整课合成任务，可查看进度、失败原因及重试结果。完成后导出 MP4 视频与字幕文件，由教师自行分发。

首版交付 PPT/PPTX 上传与逐页预览、口播稿生成和编辑、教师素材库、预置形象和音色、任务进度及 MP4。已有演示文稿联动、片段试播和字幕编辑导出属于后续完善范围。

验收时，教师能上传一节课的 PPT 并生成逐页口播稿，上传经授权的形象与参考音频，预览并修改其中一个片段，最终导出含数字人、旁白和字幕的成片。

### 4.7 试卷生成与作业设置

教师端提供独立的试卷管理和 Word 分页编辑器。可空白新建、按章节和页码组卷、套用 Word 模板或导入带题原卷。试卷和模板副本独立保存。题型包括单选、多选、判断、填空和解答，编程、计算、论述和案例可作为标签。原卷导入以 Word 段落、编号及分组为线索，题目边界由教师确认或在正文选区手动标记。

AI 单题修改显示当前题目及候选，教师采纳后仅写入确认的题目范围，并保留题号、题型和分值。教师答案独立编辑和导出。学生卷与答案均可 PDF 分页预览和导出 DOC、DOCX。导入原卷的学生版需要教师先核对答案是否已移出正文。Agent 可以按课程资料创建试卷草稿。

默认试卷采用高校期末卷常见的 A4 版式。卷首为无框双栏信息表、考试时长和总分、横向得分表，正文按大题编号并留出分题型评分栏。空白卷保留可编辑题位。课程和教师取当前工作台信息，班级从当前课程的教学班中选择，学校和学期读取部署配置。参考答案默认按题型组织，可在同一个 Word 编辑器中独立编辑。题目或试卷更新后保留已保存的答案文档，并提示教师复核。

答题卡从已确认的题型、题号和选项生成。填空区支持调整每空长度与下划线，主观作答区支持宽度、行数、行高和留空、横线或边框。编程和作图默认使用空白框。答题卡可在 Word 编辑器中独立修改、预览和导出。原卷题目或卷头更新时提示核对，重排已手改的答题卡需确认。作答区按所需书写空间预留，避免用大小暗示答案长度。[试卷与答题纸版式研究](https://eprints.whiterose.ac.uk/id/eprint/102494/1/Lonsdale%2C%20M%202007_IDJ_Text%20and%20question%20%26%20answer%20sheet%20layout.pdf) · [加州大学伯克利分校命题指南](https://berkeley-cdss.github.io/docs/course-logistics/exams/writing-exams/)

试卷及参考答案的 Word 编辑器提供公式按钮和 Alt+=。公式面板支持可视输入、数学键盘、LaTeX 和实时预览。题目信息的参考答案和评分要点可单独插入公式，并即时预览。AI 组卷和单题替换将受支持的 LaTeX 写入 Word 原生公式。已有试卷在打开时转换已标记题目里的可识别公式。填写或编辑矩阵等复杂公式后，使用普通 PDF 预览核对打印分页。

LaTeX 支持从题目、参考答案字段和答题区设置生成试卷、参考答案和答题卡的源文件及 PDF。Word 的自由排版和复杂对象通过原有 Word/PDF 导出。服务端 XeLaTeX 只编译平台生成的源文件，转义普通文本，限制公式命令、输入大小和编译时间。

教师可从题库选题或按知识点、题型、题量、分值和难度要求生成新题。组卷时检查题数与分值，提示重复题和答案缺失。生成题目进入待审核状态。教师确认题目、参考答案及评分规则后保存试卷，可分别导出学生用卷与教师答案，或将选定版本作为作业。

验收时，教师能为指定知识范围生成试卷，修订题目并确认总分、题型结构及评分规则。修改题目后可保留之前发布或用于批改的试卷版本。

### 4.8 作业批改

学生端上线前，教师导入按学号、题目和教学任务版本匹配的电子作答记录，检查缺交、无法匹配和重复提交。客观题按确认的答案计分。主观题生成分项评分建议、答卷依据和评语草稿，教师可逐份复核并确认成绩与反馈。改分记录保存操作者、时间及变更前后的分数。

验收时，教师能导入一个班的作答，处理一条匹配异常，核查客观题得分，修改一条主观题评分建议，并导出确认后的成绩与评语。

### 4.9 学情分析与讲评

教师可导入 CSV、XLS 和 XLSX 格式的成绩、作业、考勤及其他经字段映射确认的表格。系统提供样例预览、映射模板、校验报告及重复导入检查；教师确认后按字段映射生成班级当前大屏、历史趋势和个人档案。显示有效样本数、缺失值、统计口径和来源批次；只在有题目/知识点数据时提供相关分析，不以缺少的数据推断学生水平。

教师可针对班级或指定学生生成后续教学/学习计划草稿，AI 只辅助撰写，统计事实由后端计算；推荐资源必须来自四类已发布资源池并附匹配依据，教师编辑确认。个人计划仅能由教师和指定学生查看，未经确认不向学生发布。学情分析的产品范围、字段映射/大屏模板、数据模型、隐私边界与技术建议见[学情分析与资源共享设计 v0.1](learning-analytics-design.md)。

验收时，教师用不同格式和列名的成绩、作业、考勤文件完成映射与导入，能够检查当前、历史和单学生视图，追溯一个指标到来源行，生成并修订计划草稿，并将计划推荐到已有的已发布资源。

### 4.10 教师 Agent 对话窗口

教师可以直接使用各功能页面，也可以从教师工作台打开独立的 Agent 全页对话。对话显示当前课程上下文，并按课程保存历史记录。教师可切换历史对话、停止当前回复；回复期间默认把新消息排队，也可选择引导以停止当前回复并立即按新要求继续。Agent 回复中的 Markdown 在清洗后排版显示。当操作所需的章节、资料或作业范围存在歧义时，Agent 先让教师明确范围。Agent 执行真实的业务操作，并将任务状态、成果链接或失败原因返回对话。

| 功能 | Agent 可执行的操作 | 功能页面承载的操作 |
| --- | --- | --- |
| 教案 | 已支持读取列表与正文。按目标、课时和资料生成，以及修改教案，待接入 | Word 分页编辑、模板管理、版本保存与导出 |
| 知识框架与架构图 | 从已选资料提取知识框架，基于选定版本生成架构图 | 层级与关系编辑、图稿预览和导出 |
| 课件 PPT | 查询课件与模板，读取单页内容，使用教案和资料生成草稿，为指定页提出修改候选 | 确认候选、编辑与放映、管理模板、预览 PDF 与导出可编辑 PPTX |
| 试卷 | 根据知识点、题量和分值要求生成试卷草稿 | 逐题审核，确认评分规则与试卷版本 |
| 作业批改 | 对已导入且匹配成功的指定批次启动批改、查询进度 | 导入与匹配校验，核查主观题得分、确认成绩及公开反馈 |
| 学情分析 | 查询授权范围内的统计，生成讲评提纲与补练建议 | 查看统计明细、筛选、追溯到题目和答卷 |
| 共享资源池 | 搜索教师已发布的 PPT、题库、思维导图和数字课程，按学科/课程/章节/关键词筛选；创建待审核计划并引用真实资源 | 编辑内容与元数据、发布/更新/下架版本；学生端独立呈现资源详情与本人计划 |
| 数字课程 | 提供数字课程页面入口 | 上传 PPT、生成和编辑口播稿、上传形象及参考语音、预览、渲染与导出 |

功能页面和 Agent 共用业务校验、权限、任务与成果记录。由对话创建的草稿进入对应功能页面，教师在页面编辑和确认。对话可串联多个生成工具，每一步均记录所用资料和版本。数字课程的制作流程整体由专用页面驱动。

验收时，教师能在同一段对话中基于已选资料生成教案与 PPT 草稿，查看进度，打开 PPT 功能页接着编辑。对话能查询本班已确认的统计。跨班查询按任课权限拦截。数字课程请求可引导教师打开专用页面。

## 5. 教学成果与两端衔接

- 生成过程区分排队、处理中、成功与失败。生成成功的内容先保存为草稿，教师确认后产生可引用版本。教师可选择使用已有版本，并在原草稿基础上继续编辑。
- 学生端后续读取教师发布的教学任务与指定内容版本。每次作答关联学生、教学班、教学任务和任务版本。批改确认与反馈公开分别记录，由教师决定反馈何时可见。
- 四类教学成果分别保留原功能编辑器，由平台共享目录统一索引已发布的不可变版本。共享目录记录发布人、发布时间、资源类型、标题、摘要、课程、学科、学期、章节和关键词；默认开放给所有登录学生检索。下架状态在搜索与详情接口同时校验。
- 学情分析数据按教师任课范围授权，学生资源池仅存教学资源元数据和公开版本引用。班级统计、原始上传文件、学生身份以及个人计划不因资源池开放而成为公开数据。
- 教师端首期可创建教学任务和导入作答，并导出确认后的批改结果。学生端启用后，在线提交进入同一批改流程。
- 教学资料和学生记录按角色、学校及课程授权。对任课分配、内容发布、成绩变更等业务动作保留记录。耗时的导入、生成和合成任务提供进度、失败反馈及重试，重试时保留已完成的成果。

## 6. 建议开发顺序

1. 保持现有登录、课程与任课授权、教师工作区及资料管理；管理端停止扩展。
2. 教案生成页面与教师 Agent 对话窗口，验证两种入口共用业务操作和生成结果。
3. 教师创作能力按组件验收：知识框架、知识架构图、PPT、题库、试卷与作业设置、数字课程。
4. 学情分析（格式多样的表格导入、当前/历史/个人分析、教学与学习计划）及平台级四类共享资源目录，逐步接入 Agent 工具。
5. 学生身份来源确认后启动独立学生端；接入已发布共享资源池和指定个人计划，再按单独设计实现作答等学生功能。

各组件可独立验收。数字课程场景如需提前验证，可在课件产出可用后安排一节课程的试制。

## 7. 组件选型、开发与验收

在线题库的自主练习定位已于 2026-11-19 确认，教师端题库、封面、答案与发布，以及后续学生作答的详细设计见[在线题库设计 v0.1](online-question-bank-design.md)。具体技术方案待审阅，不与试卷打印流程混用。

- **选型讨论**。每个组件开发前，先确定输入、预期输出、候选方案与验证样例。以调研当时的主流方案为候选，使用官方文档、原始论文或公开评测作为依据，比较效果、中文与目标学科适配、成本、延迟、部署方式、许可、数据处理方式与维护情况。对影响真实使用的关键问题安排小样验证，和项目负责人确认后更新[技术栈与选型记录](technology-stack.md)。
- **工程规范**。待架构和技术栈确认后，将模块边界、接口契约、代码风格、变更审查和发布规则写入工程规范。按可独立验证的变更提交，保持接口行为一致，对权限、版本、输入校验、失败恢复和错误日志作明确处理。
- **验证与验收**。保留关键业务链路、权限隔离、成绩及统计正确性、任务失败恢复所需的自动化验证。每个生成类组件保留代表性输入和验收步骤，功能体验及教学产出由项目负责人验收。
- **日志与 GitHub**。持续记录已完成事项、设计与选型决定、验证结果和未决事项。按独立变更提交代码与对应文档，持续同步至 [weiyu687/Dianoia](https://github.com/weiyu687/Dianoia)。
